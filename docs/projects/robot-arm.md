# Five-degree-of-freedom robot arm

**Personal project · July–December 2024**

I built a five-degree-of-freedom robot arm with a gripper, focusing on circuit design and integrating the electronics with the mechanism.

![A five-degree-of-freedom robot arm with a gripper.](/images/robot-arm.webp)

## Design and implementation

Most of the mechanical design came from [HowToMechatronics' robot arm project](https://howtomechatronics.com/tutorials/arduino/diy-arduino-robot-arm-with-smartphone-control/). I used that design as a starting point to build the system and develop its circuitry, gaining practical experience with C++, control systems, CAD, and 3D printing.
